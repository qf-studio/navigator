# Pitfall: Subprocess test suites that spawn hooks/nav_dispatch.py must set NAVIGATOR_CONFI

## Summary
Subprocess test suites that spawn hooks/nav_dispatch.py must set NAVIGATOR_CONFIG_HOME to a temp dir: per-person settings (ADHD switch, ~/.config/navigator) otherwise leak from the developer's machine into golden/dispatch output. Three suites failed at the v7.9.0 release until tier1, nav_dispatch, manifest, golden corpus and session_start tests isolated it (4b2ae38). [hooks/nav_hook_lib/personal.py]
