# Pitfall: Only one Claude Code process can bind the OTel exporter port 9464; later session

## Summary
Only one Claude Code process can bind the OTel `prometheus` exporter port 9464; later sessions export nothing, silently, and /nav shows $0.00 today. Fixed by routing OTLP through the collector in .agent/grafana (TASK-101) with OTEL_METRICS_EXPORTER=otlp in ~/.claude/settings.json; the pane says `this session not in prometheus` and session start warns when the prometheus exporter is still set (TASK-102). Check lsof -nP -iTCP:9464 -sTCP:LISTEN if it recurs

## Details
Only one Claude Code process can bind the OTel `prometheus` exporter port 9464; later sessions export nothing, silently, and /nav shows $0.00 today. Fixed by routing OTLP through the collector in .agent/grafana (TASK-101) with OTEL_METRICS_EXPORTER=otlp in ~/.claude/settings.json; the pane says `this session not in prometheus` and session start warns when the prometheus exporter is still set (TASK-102). Check lsof -nP -iTCP:9464 -sTCP:LISTEN if it recurs

## Recommended Approach
Use OTLP to the local collector (`.agent/grafana/otel-collector-config.yml`), never `OTEL_METRICS_EXPORTER=prometheus` on a machine that runs more than one session. Verified 2026-10-14: pid 69880 held :9464 since 2026-10-09, five later sessions exported nothing; the pane's today query returned 0 while the 7-day query returned $87.
