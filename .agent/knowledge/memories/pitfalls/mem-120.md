# Pitfall: A markdown header regex such as ^#{1,2}\s matches '# comment' lines inside fence

## Summary
A markdown header regex such as ^#{1,2}\s matches '# comment' lines inside fenced bash blocks: nav-sync-claude cut every custom CLAUDE.md section at its first fence (Pilot file, 2026-11-01, 98 changed lines). Scan headers with a fence state machine (``` and ~~~, same char closes) before any section logic; _scan_headers in claude_updater.py is the one scanner since v8.4.12.
