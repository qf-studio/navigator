# Pitfall: CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1 makes Claude Code refuse every mod $.

## Summary
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1 makes Claude Code refuse every mod $.http.fetch (loopback included) with no visible error; the mod's typed judge was silently dead for a day. Any mod network call needs a curl fallback via $.process.run (key in env, body on stdin) and a test with http that throws (TASK-84, v8.0.0)
