# Pitfall: A mod Svg on Claude Code Desktop is drawn as an image: markup with width="100%" 

## Summary
A mod Svg on Claude Code Desktop is drawn as an image: markup with width="100%" has no intrinsic size and falls back to 300x150 CSS px (a trend chart as tall as its card, v8.4.6). Give the svg absolute width/height attributes (the surface clamps the width to the slot, preserveAspectRatio=none stretches) and pass the element a height prop in px (TASK-108, v8.4.7).
