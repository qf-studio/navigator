## Summary
Claude Code Desktop 3.1623 on engine 2.1.299 reports Pane isFocused=true after a click inside a mod pane while the composer keeps the real keyboard: the pressed hotkey letter lands in the prompt box and no ui.press fires, and the desktop draws a key chip for every Button hotkey. Filed as anthropics/claude-code#103773. The pane passes no hotkey prop on remote surfaces (hk() in the pane hook, v8.4.11); restore them when a desktop build fires the keys. Hotkeys work in the terminal (/nav opens with focus: true).

Discovered during development.
