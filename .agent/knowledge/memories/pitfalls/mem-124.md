# Pitfall: Python 3.9 is the floor: macOS system Python and the Pilot box

## Summary
Hook runtime and skill scripts must import and test green on Python 3.9. A PEP 604 annotation without 'from __future__ import annotations' or a 3.10-only stdlib attribute breaks the Pilot gate while CI on 3.12 stays green.

## Context
2026-11-06: code_analyzer.py 'str | Path' and the stdlib-purity guard's sys.stdlib_module_names made main red on the box for six GH-42 runs.

## Details
CI test.yml runs make test on 3.9 (ubuntu-24.04; setup-python has no 3.9 build for Ubuntu 26.04) and 3.12; make mod-gen-check stays on 3.12 because one fixture renders differently under 3.9.

## Recommended Approach
Before pushing Python, run make test with a 3.9 interpreter (Xcode ships 3.9.6). Avoid X | Y annotations, match statements and 3.10-only attributes without a guard.
