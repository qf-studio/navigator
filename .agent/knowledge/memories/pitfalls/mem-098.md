# Pitfall: Deploy QuantFlow AWS job can be cancelled by the runner ~5 min into the CloudFor

## Summary
Deploy QuantFlow AWS job can be cancelled by the runner ~5 min into the CloudFormation wait while the ECS rolling update (~7 min) continues; wait for UPDATE_COMPLETE, then gh run rerun --failed so the CDN invalidation runs
