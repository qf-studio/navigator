## Summary
Prometheus increase() undercounts Claude Code OTel counters: a session's first push already carries its totals (no observed rise) and a laptop asleep across the window edge leaves live series without a sample, so offset misses them. Use per-series max_over_time(x[R]) - last_over_time(x[1d] offset R), or the whole max when none (ui/trip.ts, v8.0.0)
