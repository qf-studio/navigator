# Pitfall: Mods: $.state survives hot reload, so a changed value shape (new field) reaches 

## Summary
Mods: $.state survives hot reload, so a changed value shape (new field) reaches the new module as the OLD object; a ui.render that dereferences the new field throws, the engine skips the hook and the pane renders empty. Read state through helpers that merge stored values over defaults. The test kit cannot seed stale state: $ has no state noun and state.get is not interceptable by a prepend inline plugin.
