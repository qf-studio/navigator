# Pitfall: Claude Code mods static scan: $ is followed only into functions declared in the 

## Summary
Claude Code mods static scan: $ is followed only into functions declared in the hooks module itself, never across an import ('$ is passed to X, imported from ./y'). Multi-file mods must pass a capability object built in register.tsx (each method a direct $.noun.method call) to imported modules; validate still lists the calls 'via ioOf'. Atoms touched through $ must also live in the hooks module. Navigator v8 uses an Io port (hooks/mod/lib/types.ts).
