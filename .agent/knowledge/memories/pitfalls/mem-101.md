# Pitfall: release_validator --verify-hooks run inside a Claude Code session inherited NAVI

## Summary
release_validator --verify-hooks run inside a Claude Code session inherited NAVIGATOR_MOD_OWNS, so the Python dispatcher exited silently on every mod-owned op and three payload events showed the v6.14.0 silent-fail signature (20/26); since v8.3.5 the smoke test scrubs NAVIGATOR_MOD_OWNS and PILOT_EXECUTOR and binds the set path to the repo under release, the unset path to a tmp HOME whose marketplace fallback links to the repo (26/26 anywhere)
