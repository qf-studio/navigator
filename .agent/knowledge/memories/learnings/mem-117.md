# Learning: Desktop pane spacing is numeric cells only while MIN_CC is 2.1.287 (Space step n

## Summary
Desktop pane spacing is numeric cells only while MIN_CC is 2.1.287 (Space step names are 2.1.299 types): one cell down is about a text row, one cell across about 14 px. The desktop reads a gap set on the other axis of a Box as space too, so set rowGap only on a column Box and columnGap only on a row Box; the terminal shows a row between card frames on its own, so gaps are remote-only (TASK-108, v8.4.7-v8.4.10).
