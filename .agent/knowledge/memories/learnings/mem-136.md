# Learning: No judge row and no j button in the /nav pane of a project means no verdict exis

## Summary
No judge row and no j button in the /nav pane of a project means no verdict exists there: judge.enabled is a per-project setting that ships off (this repo has it on), or the first prompt of the session is not judged yet, or the call timed out. It is not a pane defect; check the session-start line 'Typed judge: on' and judge.py --check
