# Learning: Claude Code 2.1.299 narrowed the mod network policy: CLAUDE_CODE_DISABLE_NONESSE

## Summary
Claude Code 2.1.299 narrowed the mod network policy: CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1 refuses only built-in requests and plugin $.http.fetch calls that carry an auth handle; a plain mod fetch to api.github.com answered 200 and loopback failed with ECONNREFUSED (socket, not policy) in a -p probe on 2026-10-19. The curl fallback (judge io.runWith, auto_update.curl_fallback) stays for 2.1.287-2.1.28x; earliest relaxed version unknown (not in the embedded changelog 2.1.289-2.1.296). Supersedes mem-086 for new CC.
