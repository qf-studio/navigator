## Summary
Claude Code hooks modules (mods): on CC < 2.1.287 they are behind rollout flag tengu_plugin_hooks_modules / CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1; with the flag off, a plugin whose hooks/hooks.json carries 'modules' still loads its classic hooks and only logs 'hooks module not loaded' (stderr under -p). Verified on 2.1.284, 2026-10-02 (TASK-84 M6).
