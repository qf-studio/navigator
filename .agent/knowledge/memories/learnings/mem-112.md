# Learning: Claude Code embeds its plugin API declarations in the binary as a zstd blob name

## Summary
Claude Code embeds its plugin API declarations in the binary as a zstd blob named claude-code.d.ts-<hash>.txt.zst (hash changes when the API changes: e37ccc4a on 2.1.287, 632d5898 on 2.1.299) and the test kit as kit-modules.js-<hash>.txt.zst; the engine writes .claude-plugin/types/ only while a mod is developed in an interactive session (2.1.295), never in -p, so the repo copy can go stale. To diff API versions: scan the binary for zstd magic 28B52FFD, stream-decompress, keep the blob whose head says 'Claude Code function hooks'; recipe and outputs in .agent/research/claude-code-mods-2026-10-19/.
