## Summary
stop_completion classifies a Bash command it does not recognise as mutating (over-fire direction by design), so a read-only turn that uses a python3 heredoc, sed or grep pipeline can trigger a forced continuation when stop_completion.continue_enabled is on (this repo). Expect 'this turn mutated the codebase' on diagnostic turns; either accept it, extend the read-only allowlist, or turn continue_enabled off locally. [hooks/ops/stop_completion.py]
