# Learning: A release gate that executes manifest hooks must build its own environment: scru

## Summary
A release gate that executes manifest hooks must build its own environment: scrub session variables that change hook behaviour (NAVIGATOR_MOD_OWNS, PILOT_EXECUTOR), point the set path at the code under release rather than a cached install, and fake the unset-path fallback with a tmp HOME + symlink so a runner without the real directory tests the plugin, not the machine
